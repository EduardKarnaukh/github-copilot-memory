---
name: remember
description: Save something to the project's persistent memory. Use when the user says "remember", "save this to memory", "don't forget", or at the end of a long task to capture what is worth keeping from the session.
---

Follow the Memory rules from the app instructions.

1. Resolve the memory directory for the current project and read its `MEMORY.md`.
2. If the user named something to remember, save exactly that. If it is already
   recorded in the repo (code, git history, instruction files), ask what was
   non-obvious about it and save that instead.
3. Otherwise go through this session and save whatever qualifies: corrections and
   confirmed approaches (`feedback`), decisions, traps and unfinished work
   (`project`), facts about the user (`user`), external pointers (`reference`).
   If nothing qualifies, say so.
4. Update an existing file instead of creating a duplicate. Add or update the
   one-line pointer in `MEMORY.md`.
5. Report which files you created or changed.
